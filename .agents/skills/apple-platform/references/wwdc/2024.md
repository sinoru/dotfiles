2024년 9월 출시. Apple Intelligence 발표, 탭바+사이드바 통합(UITab/sidebarAdaptable), UIKit-SwiftUI 상호운용 심화, TVML 종료.

## SwiftUI (iOS 18 / macOS 15)

### 매크로·상태
- **`@Entry`** — EnvironmentValues/Transaction/ContainerValues/FocusedValues 키 보일러플레이트 제거. iOS 13까지 back-deploy.
- **`@Previewable`** — `#Preview` 안에서 `@State` 직접 사용.

### 탭·네비게이션
- **`Tab` 구조체 문법** — `TabView { Tab("Home", systemImage: "house") { … } }`.
- **`.tabViewStyle(.sidebarAdaptable)`** — iPad 탭바 ↔ 사이드바 전환. 상세는 `../cross-platform.md`.
- **줌 전환** — `.navigationTransition(.zoom)` + `.matchedTransitionSource(id:in:)`.

### 커스텀 컨테이너
- **`ForEach(subviewOf:)`**, **`Group(subviews:)`**, **`ContainerValues`** — 서브뷰 단위 커스텀 컨테이너 구축.

### 그래픽·텍스트
- **`MeshGradient`** — 메시 기반 그라디언트.
- **`TextRenderer`** 프로토콜 — 커스텀 텍스트 렌더링/애니메이션.
- **`Color.mix(with:by:)`**, SF Symbols 6 이펙트(wiggle, breathe, rotate).

### 스크롤·프레젠테이션
- **`.onScrollGeometryChange(for:of:)`** / **`.onScrollVisibilityChange(threshold:)`** — GeometryReader 없는 스크롤 추적.
- **`.presentationSizing(_:)`** — 시트 크기 프리셋(form/page).

### macOS 15 윈도우
- **`UtilityWindow`** scene, **`.defaultWindowPlacement { }`** / **`.windowIdealPlacement`**, plain window style, 윈도우 타일링(`cascadingReferenceFrame`).

## UIKit (iOS 18)

- **자동 trait 추적** — `layoutSubviews` 등에서 읽은 trait 변경 시 자동 무효화. `registerForTraitChanges` 수동 등록 대체.
- **`UITab` / `UITabGroup`** — 탭바+사이드바 결합, iPadOS 플로팅 탭바. 드래그 앤 드롭 커스터마이즈.
- **`UIUpdateLink`** — `CADisplayLink`보다 세밀한 디스플레이 업데이트, 가시성 기반 자동 활성화.
- **SwiftUI 애니메이션 브릿지** — `UIView.animate(springDuration:)` 등에서 SwiftUI `Animation` 타이밍 사용.
- **제스처 상호운용** — `UIGestureRecognizerRepresentable`(SwiftUI에서 UIKit 제스처), 크로스 프레임워크 제스처 의존성.
- **줌 전환** — UIKit 네비게이션에도 zoom transition 지원.
- **문서 launch 경험** — `UIDocumentViewController.LaunchOptions` + SwiftUI `DocumentGroupLaunchScene` (기반 클래스 자체는 iOS 17).

## AppKit (macOS 15 Sequoia)

- **`NSHostingMenu`** — SwiftUI로 정의한 메뉴를 AppKit에서 사용 (가용성은 macOS 14.4+, WWDC24 소개).
- **SwiftUI 애니메이션** — `NSAnimationContext.runAnimationGroup`에서 SwiftUI `Animation` 사용.
- 텍스트: `textHighlight` 속성, `NSTextField` 입력 제안(suggestions).
- 커서 API: `NSCursor.frameResize` / `.columnResize` / `.zoomIn` / `.zoomOut`.
- `NSSavePanel.showsContentTypes` — 파일 형식 피커.

## watchOS 11

- **Live Activities** — iOS Live Activity가 Smart Stack에 자동 표시. `.supplementalActivityFamilies([.small])`로 워치 전용 레이아웃. 상세는 `../platforms/watchos.md`.
- **`AccessoryWidgetGroup`** — accessoryRectangular에 3개 뷰 수평 배치.
- **더블 탭** — `.handGestureShortcut(.primaryAction)`으로 기본 액션 지정.
- 위젯 인터랙티비티(Button/Toggle) watchOS 지원.

## tvOS 18

- **TVML / TVMLKit deprecated** → SwiftUI 마이그레이션 (WWDC 2024 세션 10207).
- **사이드바 TabView** — `.tabViewStyle(.sidebarAdaptable)`.

## visionOS 2

- 리사이즈 가능 Volume + `.volumeBaseplateVisibility` + `.onVolumeViewpointChange`.
- **커스텀 Hover Effect** (`CustomHoverEffect`).
- ARKit: **Room Tracking**, **Object Tracking**, hand tracking display-rate 전달·예측.
- 동적 조명/그림자, Portal Crossing, 물리 관절.
- **TabletopKit** — 공간 테이블탑 게임.
- Enterprise API (카메라 접근, 바코드, Neural Engine — 관리 entitlement).

## SwiftData (iOS 18)

- **`#Index`** / **`#Unique`** 매크로 — 인덱스·유니크 제약.
- **커스텀 DataStore** — 저장 백엔드 교체 (SQLite, 웹서비스 등).
- **History API** — 변경 이력 추적.

## 플랫폼 공통 / Apple Intelligence

- **Apple Intelligence** — Writing Tools(표준 텍스트 뷰 자동, iOS 18.1), Image Playground·Genmoji(iOS 18.2 출시).
- **App Intent Domains** — `@AssistantIntent(schema: .photos.createAlbum)` (도메인은 스키마 키패스에 포함; 엔티티는 `@AssistantEntity(schema:)`). 12개 도메인, Mail·Photos부터 순차 제공.
- **`IndexedEntity`** — Spotlight 시맨틱 검색에 앱 엔티티 제공.
- **Control Center Controls** — `ControlWidget` (Control Center / 잠금화면 / Action 버튼).
- **앱 아이콘 변형** — dark / tinted 아이콘.
- **RealityView 크로스 플랫폼화** — iOS 18 / macOS 15로 확장.
- **Translation 프레임워크** — 온디바이스 번역 API.
- **AccessorySetupKit** — 블루투스/Wi-Fi 액세서리 페어링.
- Swift Charts: **함수 플로팅** (`LinePlot`), 벡터화 플롯.
- StoreKit: **win-back 오퍼**, `SubscriptionStoreView` 커스텀 컨트롤 스타일.
- **LockedCameraCapture** — 잠금 상태 카메라 캡처 확장.
- **자동 passkey 업그레이드** (AuthenticationServices) — 로그인 시 자동 passkey 등록.
- **FSKit** (macOS 15) — 유저스페이스 파일시스템.
- **Vision 프레임워크 신규 Swift API**.
