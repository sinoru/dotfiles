# WWDC 2024 — iOS 18 · iPadOS 18 · macOS 15 Sequoia · watchOS 11 · tvOS 18 · visionOS 2

Released September 2024. Apple Intelligence announced, tab bar + sidebar unification (UITab/sidebarAdaptable), deeper UIKit-SwiftUI interop, TVML retired.

> Previous: `2022.md` → `2023.md` · Later: `2025.md` (Liquid Glass) → `2026.md`

## SwiftUI (iOS 18 / macOS 15)

### Macros/state
- **`@Entry`** — removes boilerplate for EnvironmentValues/Transaction/ContainerValues/FocusedValues keys. Back-deployed to iOS 13.
- **`@Previewable`** — use `@State` directly inside `#Preview`.

### Tabs/navigation
- **`Tab` struct syntax** — `TabView { Tab("Home", systemImage: "house") { … } }`.
- **`.tabViewStyle(.sidebarAdaptable)`** — switches between iPad tab bar ↔ sidebar. Details in `../cross-platform.md`.
- **Zoom transition** — `.navigationTransition(.zoom)` + `.matchedTransitionSource(id:in:)`.

### Custom containers
- **`ForEach(subviewOf:)`**, **`Group(subviews:)`**, **`ContainerValues`** — build custom containers at the subview level.

### Graphics/text
- **`MeshGradient`** — mesh-based gradients.
- **`TextRenderer`** protocol — custom text rendering/animation.
- **`Color.mix(with:by:)`**, SF Symbols 6 effects (wiggle, breathe, rotate).

### Scroll/presentation
- **`.onScrollGeometryChange(for:of:)`** / **`.onScrollVisibilityChange(threshold:)`** — scroll tracking without GeometryReader.
- **`.presentationSizing(_:)`** — sheet sizing presets (form/page).

### macOS 15 windowing
- **`UtilityWindow`** scene, **`.defaultWindowPlacement { }`** / **`.windowIdealPlacement`**, plain window style, window tiling (`cascadingReferenceFrame`).

## UIKit (iOS 18)

- **Automatic trait tracking** — traits read in `layoutSubviews` etc. automatically invalidate on change. Replaces manual `registerForTraitChanges` registration.
- **`UITab` / `UITabGroup`** — combines tab bar and sidebar, iPadOS floating tab bar. Drag-and-drop customization.
- **`UIUpdateLink`** — finer-grained display updates than `CADisplayLink`, automatic activation based on visibility.
- **SwiftUI animation bridge** — use SwiftUI `Animation` timing in e.g. `UIView.animate(springDuration:)`.
- **Gesture interop** — `UIGestureRecognizerRepresentable` (UIKit gestures in SwiftUI), cross-framework gesture dependencies.
- **Zoom transition** — zoom transition support also in UIKit navigation.
- **Document launch experience** — `UIDocumentViewController.LaunchOptions` + SwiftUI `DocumentGroupLaunchScene` (the base class itself dates to iOS 17).

## AppKit (macOS 15 Sequoia)

- **`NSHostingMenu`** — use menus defined in SwiftUI from AppKit (available since macOS 14.4+, introduced at WWDC24).
- **SwiftUI animation** — use SwiftUI `Animation` in `NSAnimationContext.runAnimationGroup`.
- Text: `textHighlight` attribute, `NSTextField` input suggestions.
- Cursor API: `NSCursor.frameResize` / `.columnResize` / `.zoomIn` / `.zoomOut`.
- `NSSavePanel.showsContentTypes` — file format picker.

## watchOS 11

- **Live Activities** — iOS Live Activities automatically appear in the Smart Stack. `.supplementalActivityFamilies([.small])` for watch-specific layouts. Details in `../platforms/watchos.md`.
- **`AccessoryWidgetGroup`** — arranges 3 views horizontally in accessoryRectangular.
- **Double Tap** — specify the default action with `.handGestureShortcut(.primaryAction)`.
- Widget interactivity (Button/Toggle) support on watchOS.

## tvOS 18

- **TVML / TVMLKit deprecated** → migrate to SwiftUI (WWDC 2024 session 10207).
- **Sidebar TabView** — `.tabViewStyle(.sidebarAdaptable)`.

## visionOS 2

- Resizable Volume + `.volumeBaseplateVisibility` + `.onVolumeViewpointChange`.
- **Custom Hover Effect** (`CustomHoverEffect`).
- ARKit: **Room Tracking**, **Object Tracking**, hand tracking display-rate delivery and prediction.
- Dynamic lighting/shadows, Portal Crossing, physics joints.
- **TabletopKit** — spatial tabletop games.
- Enterprise API (camera access, barcode, Neural Engine — managed entitlement).

## SwiftData (iOS 18)

- **`#Index`** / **`#Unique`** macros — index/uniqueness constraints.
- **Custom DataStore** — swap out storage backends (SQLite, web service, etc.).
- **History API** — change history tracking.

## Cross-Platform / Apple Intelligence

- **Apple Intelligence** — Writing Tools (automatic in standard text views, iOS 18.1), Image Playground · Genmoji (shipped iOS 18.2).
- **App Intent Domains** — `@AssistantIntent(schema: .photos.createAlbum)` (the domain is included in the schema key path; entities use `@AssistantEntity(schema:)`). 12 domains, rolling out starting with Mail and Photos.
- **`IndexedEntity`** — expose app entities to Spotlight semantic search.
- **Control Center Controls** — `ControlWidget` (Control Center / Lock Screen / Action button).
- **App icon variants** — dark / tinted icons.
- **RealityView goes cross-platform** — extended to iOS 18 / macOS 15.
- **Translation framework** — on-device translation API.
- **AccessorySetupKit** — Bluetooth/Wi-Fi accessory pairing.
- Swift Charts: **function plotting** (`LinePlot`), vectorized plots.
- StoreKit: **win-back offers**, `SubscriptionStoreView` custom control styles.
- **LockedCameraCapture** — extends camera capture to the locked state.
- **Automatic passkey upgrade** (AuthenticationServices) — automatic passkey registration at sign-in.
- **FSKit** (macOS 15) — userspace file systems.
- **New Swift API for the Vision framework**.

## Deprecated (2024 cycle)

| Deprecated | Replacement |
|---|---|
| TVML / TVMLKit (tvOS 18) | SwiftUI |
| StoreKit Original API (officially deprecated in iOS 18) | StoreKit 2 |
| Manual `registerForTraitChanges` registration (no longer needed) | Automatic trait tracking |
