# WWDC 2023 — iOS 17 · iPadOS 17 · macOS 14 Sonoma · watchOS 10 · tvOS 17 · visionOS 1

Released September 2023 (visionOS 1 shipped in February 2024 with Vision Pro). Observation (@Observable) and SwiftData debut, full watchOS navigation overhaul, visionOS unveiled.

> Previous: `2022.md` · Later: `2024.md` → `2025.md` (Liquid Glass) → `2026.md`

## Observation & SwiftData (iOS 17 / macOS 14 / watchOS 10 / tvOS 17)

- **`@Observable` macro** (Observation framework) — replaces `ObservableObject` + `@Published`. Per-property tracking. `@StateObject`→`@State`, `@ObservedObject`→plain property/`@Bindable`, `@EnvironmentObject`→`@Environment(Type.self)`. Details in `../swiftui.md`.
- **SwiftData** — `@Model`, `@Query`, `ModelContainer`, `@ModelActor`. Swift-native replacement for Core Data. Details in `../swiftui.md`.
- **`#Predicate` macro** (Foundation) — replaces `NSPredicate`, compile-time type checking.

## SwiftUI (iOS 17 / macOS 14)

### Extended scroll API
- **`.scrollTargetBehavior(.paging / .viewAligned)`** + **`.scrollTargetLayout()`** — snap scrolling.
- **`.scrollPosition(_:)`** — read/control scroll position.
- **`.containerRelativeFrame(_:)`** — sizing based on container proportions.
- **`.scrollTransition(_:)`** — visibility-based transition effects.

### Animation/effects
- **`PhaseAnimator`** / **`KeyframeAnimator`** — multi-phase/keyframe animation.
- **`.symbolEffect(_:)`** — SF Symbols animation (bounce, pulse, variableColor …).
- **`.sensoryFeedback(_:trigger:)`** — haptics.
- **`.visualEffect { }`** — geometry-based effects without GeometryReader.
- **Metal shader modifiers** — `.colorEffect` / `.layerEffect` / `.distortionEffect` + `ShaderLibrary`.

### New views/features
- **`#Preview` macro** — replaces `PreviewProvider` (also supports UIKit/AppKit views).
- **`ContentUnavailableView`** — standard empty-state view (`.search` preset).
- **`.inspector(isPresented:)`** — trailing inspector panel (macOS/iPadOS).
- **MapKit for SwiftUI** — `Map`, `Marker`, `Annotation`, `MapContentBuilder`.
- **`.onKeyPress(_:)`** (iOS 17 / macOS 14 / tvOS 17) — hardware keyboard input for focusable views.

### Widgets
- **Interactive widgets** (iOS 17) — `Button` / `Toggle` + `AppIntent`.
- **`AppIntentTimelineProvider`** — widget configuration moves to be App Intents-based (`IntentTimelineProvider` is legacy).
- **`.containerBackground(_:for: .widget)`** — widget background responsive to StandBy/Lock Screen.
- **Expanded widget surfaces** — StandBy (iOS 17), iPad Lock Screen, macOS Sonoma desktop widgets (including displaying iPhone widgets on Mac).

## UIKit (iOS 17)

- **`viewIsAppearing(_:)`** — lifecycle callback fired at the accurate point for geometry/traits. Back-deployed to iOS 13. Details in `../uikit.md`.
- **`UIContentUnavailableConfiguration`** — empty-state configuration (`.empty()`, `.loading()`, `.search()`).
- **Custom traits** — `UITraitDefinition`, `registerForTraitChanges(_:)` (replaces `traitCollectionDidChange`), SwiftUI environment bridging (`UITraitBridgedEnvironmentKey`).
- **`UIDocumentViewController`** — base class for document apps (a prerequisite for the 2024 launch experience).
- **Symbol animation** — `addSymbolEffect(_:)` (UIImageView).
- **Spring animation API** — `UIView.animate(springDuration:bounce:)`.
- **`NSCollectionLayoutDimension.uniformAcrossSiblings`** — uniform sizing across sibling cells.
- Text item interaction — customizing the menu for link/data-detected items.

## AppKit (macOS 14 Sonoma)

- **Inspector API** — trailing split view (back-deployed to Big Sur).
- **`@ViewLoading` / `@WindowLoading`** — removes optionality from VC/WC properties (introduced in macOS 13.3, UIKit `@ViewLoading` in iOS 16.4 — introduced at WWDC23).
- **Menus**: `NSMenuItem.sectionHeader(title:)`, palette menus (`.presentationStyle = .palette`), menu badges.
- **`activate()`** — `activate(ignoringOtherApps:)` deprecated. Cooperative app activation + `yieldActivation(to:)`.
- NSPopover toolbar anchoring/full-size content, **`NSBezierPath.cgPath`**, **`NSView.displayLink`** (CADisplayLink on macOS).
- **NSColor system fills** (`systemFill` ~ `quinarySystemFill`), default bounds clipping removed for views.
- NSImageView: symbol effects, native HDR display.
- `Sendable`: NSColor, NSShadow · `Transferable`: NSImage, NSColor, NSSound.

## watchOS 10 — full navigation overhaul

- **Vertical TabView** — horizontal swipe → vertical Digital Crown paging. Details in `../platforms/watchos.md`.
- **`.containerBackground(_:for:)`** — background for tab/navigation transitions.
- **Toolbar placement** — `.topBarLeading` / `.topBarTrailing`, bottom bar.
- **NavigationSplitView redesign** — source list → detail.
- **Smart Stack** widgets.

## tvOS 17

- **Continuity Camera on tvOS** — tvOS's first camera/microphone API (use iPhone/iPad as a camera).

## visionOS 1 (announced 2023-06, shipped 2024-02)

- App model: **Window / Volume / ImmersiveSpace** (`.mixed` / `.progressive` / `.full`).
- **RealityView**, **Model3D**, ornaments, `.glassBackgroundEffect()`, hover effect.
- Input: gaze + pinch (indirect), direct touch, ARKit hand tracking.
- Details in `../platforms/visionos.md`.

## Cross-Platform / Other

- **TipKit** (iOS 17 / macOS 14 …) — feature discovery tips. Details in `../platforms/ios.md`.
- **StoreKit SwiftUI views** — `ProductView` / `StoreView` / `SubscriptionStoreView`.
- **App Shortcuts** enhancements — top-of-Spotlight surfacing, automatic Siri phrasing.
- **WorkoutKit** (watchOS 10) — Custom Workout API, high-frequency CoreMotion data.
- **SensitiveContentAnalysis** — on-device sensitive content detection (Communication Safety integration).
- **Privacy manifests + third-party SDK signing** — later evolves into an App Store submission requirement.
- **Game Porting Toolkit / Metal Shader Converter** (macOS 14).

## Deprecated / Successor (2023 cycle)

| Previous | Replacement |
|---|---|
| `ObservableObject` + `@Published` (not deprecated, but superseded) | `@Observable` |
| `NSPredicate` (string-based) | `#Predicate` |
| `PreviewProvider` | `#Preview` macro |
| `IntentTimelineProvider` (widgets) | `AppIntentTimelineProvider` |
| `traitCollectionDidChange` | `registerForTraitChanges` (iOS 17) → automatic tracking (iOS 18) |
| `activate(ignoringOtherApps:)` (AppKit) | `activate()` + `yieldActivation(to:)` |
