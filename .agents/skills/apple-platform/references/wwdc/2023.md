# WWDC 2023 — iOS 17 · iPadOS 17 · macOS 14 Sonoma · watchOS 10 · tvOS 17 · visionOS 1

2023년 9월 출시 (visionOS 1은 2024년 2월 Vision Pro와 함께). Observation(@Observable)과 SwiftData 등장, watchOS 네비게이션 전면 개편, visionOS 공개.

> 이전: `2022.md` · 이후: `2024.md` → `2025.md` (Liquid Glass) → `2026.md`

## Observation & SwiftData (iOS 17 / macOS 14 / watchOS 10 / tvOS 17)

- **`@Observable` 매크로** (Observation 프레임워크) — `ObservableObject` + `@Published` 대체. 프로퍼티 단위 추적. `@StateObject`→`@State`, `@ObservedObject`→plain property/`@Bindable`, `@EnvironmentObject`→`@Environment(Type.self)`. 상세는 `../swiftui.md`.
- **SwiftData** — `@Model`, `@Query`, `ModelContainer`, `@ModelActor`. Core Data의 Swift 네이티브 대체. 상세는 `../swiftui.md`.
- **`#Predicate` 매크로** (Foundation) — `NSPredicate` 대체, 컴파일 타임 타입 체크.

## SwiftUI (iOS 17 / macOS 14)

### 스크롤 API 확장
- **`.scrollTargetBehavior(.paging / .viewAligned)`** + **`.scrollTargetLayout()`** — 스냅 스크롤.
- **`.scrollPosition(_:)`** — 스크롤 위치 읽기/제어.
- **`.containerRelativeFrame(_:)`** — 컨테이너 비율 기반 크기.
- **`.scrollTransition(_:)`** — 가시성 기반 전환 효과.

### 애니메이션·효과
- **`PhaseAnimator`** / **`KeyframeAnimator`** — 다단계/키프레임 애니메이션.
- **`.symbolEffect(_:)`** — SF Symbols 애니메이션 (bounce, pulse, variableColor …).
- **`.sensoryFeedback(_:trigger:)`** — 햅틱.
- **`.visualEffect { }`** — GeometryReader 없이 geometry 기반 효과.
- **Metal 셰이더 수정자** — `.colorEffect` / `.layerEffect` / `.distortionEffect` + `ShaderLibrary`.

### 신규 뷰·기능
- **`#Preview` 매크로** — `PreviewProvider` 대체 (UIKit/AppKit 뷰도 지원).
- **`ContentUnavailableView`** — 빈 상태 표준 뷰 (`.search` 프리셋).
- **`.inspector(isPresented:)`** — trailing 인스펙터 패널 (macOS/iPadOS).
- **MapKit for SwiftUI** — `Map`, `Marker`, `Annotation`, `MapContentBuilder`.
- **`.onKeyPress(_:)`** (iOS 17 / macOS 14 / tvOS 17) — focusable 뷰 하드웨어 키보드 입력.

### 위젯
- **인터랙티브 위젯** (iOS 17) — `Button` / `Toggle` + `AppIntent`.
- **`AppIntentTimelineProvider`** — 위젯 구성이 App Intents 기반으로 이동 (`IntentTimelineProvider`는 레거시).
- **`.containerBackground(_:for: .widget)`** — StandBy/잠금화면 대응 위젯 배경.
- **위젯 지면 확장** — StandBy(iOS 17), iPad 잠금화면, macOS Sonoma 데스크톱 위젯(iPhone 위젯의 Mac 표시 포함).

## UIKit (iOS 17)

- **`viewIsAppearing(_:)`** — geometry/traits 정확한 시점의 라이프사이클 콜백. iOS 13까지 back-deploy. 상세는 `../uikit.md`.
- **`UIContentUnavailableConfiguration`** — 빈 상태 구성 (`.empty()`, `.loading()`, `.search()`).
- **커스텀 trait** — `UITraitDefinition`, `registerForTraitChanges(_:)` (`traitCollectionDidChange` 대체), SwiftUI environment 브릿지(`UITraitBridgedEnvironmentKey`).
- **`UIDocumentViewController`** — 문서 앱 기반 클래스 (2024년 launch 경험의 전제).
- **심볼 애니메이션** — `addSymbolEffect(_:)` (UIImageView).
- **스프링 애니메이션 API** — `UIView.animate(springDuration:bounce:)`.
- **`NSCollectionLayoutDimension.uniformAcrossSiblings`** — 형제 셀 크기 통일.
- 텍스트 아이템 인터랙션 — 링크/데이터 감지 항목의 메뉴 커스터마이즈.

## AppKit (macOS 14 Sonoma)

- **Inspector API** — trailing split view (Big Sur까지 back-deploy).
- **`@ViewLoading` / `@WindowLoading`** — VC/WC 프로퍼티 optionality 제거 (도입은 macOS 13.3, UIKit `@ViewLoading`은 iOS 16.4 — WWDC23에서 소개).
- **메뉴**: `NSMenuItem.sectionHeader(title:)`, palette 메뉴(`.presentationStyle = .palette`), 메뉴 배지.
- **`activate()`** — `activate(ignoringOtherApps:)` deprecated. 협조적 앱 활성화 + `yieldActivation(to:)`.
- NSPopover 툴바 앵커링·full-size content, **`NSBezierPath.cgPath`**, **`NSView.displayLink`**(CADisplayLink on macOS).
- **NSColor system fills** (`systemFill` ~ `quinarySystemFill`), 뷰 기본 bounds 클리핑 해제.
- NSImageView: 심볼 이펙트, 네이티브 HDR 표시.
- `Sendable`: NSColor, NSShadow · `Transferable`: NSImage, NSColor, NSSound.

## 플랫폼 공통 / 기타

- **TipKit** (iOS 17 / macOS 14 …) — 기능 발견 팁. 상세는 `../platforms/ios.md`.
- **StoreKit SwiftUI 뷰** — `ProductView` / `StoreView` / `SubscriptionStoreView`.

- **Game Porting Toolkit / Metal Shader Converter** (macOS 14).

## Deprecated / 세대교체 (2023 사이클)

| 이전 | 대체 |
|---|---|
| `ObservableObject` + `@Published` (deprecated 아님, 세대교체) | `@Observable` |
| `NSPredicate` (문자열 기반) | `#Predicate` |
| `PreviewProvider` | `#Preview` 매크로 |
| `IntentTimelineProvider` (위젯) | `AppIntentTimelineProvider` |
| `traitCollectionDidChange` | `registerForTraitChanges` (iOS 17) → 자동 추적 (iOS 18) |
| `activate(ignoringOtherApps:)` (AppKit) | `activate()` + `yieldActivation(to:)` |
