# WWDC 2026 — iOS 27 · iPadOS 27 · macOS 27 Golden Gate · watchOS 27 · tvOS 27 · visionOS 27

2026년 6월 발표, 가을 출시. **UIScene 필수화**, SwiftUI 새 Document API, App Intents가 신형 Siri의 유일한 통합 표면으로, Foundation Models 대폭 확장. Intel Mac 시대 종료. 툴체인: Xcode 27, Swift 6.4, SF Symbols 8, Icon Composer 2.

> 이전: `2022.md` → `2023.md` → `2024.md` → `2025.md` (Liquid Glass 도입)

## 필수 요건 변화 (iOS 27 SDK 빌드 시)

- **UIScene lifecycle 필수** — app-delegate lifecycle만 사용하는 앱은 iOS 27 SDK로 빌드 시 **실행 자체가 실패**. 구 SDK 빌드 바이너리는 계속 동작 (SDK 기준, OS 기준 아님).
- **런치 스크린 필수** — `UILaunchScreen` 계열 Info.plist 키 없으면 App Store 제출 거부.
- **Liquid Glass opt-out 제거** — Xcode 27로 리컴파일하면 구 디자인 선택 불가.
- **리사이즈 자동 opt-in** — iOS 27 SDK로 빌드하면 iPhone 앱이 iPad·iPhone Mirroring에서 자유 리사이즈. idiom·orientation은 레이아웃 기준으로 무의미 — size class 사용. `UIRequiresFullScreen`은 "이산적 리사이즈"로 재정의.
- Xcode 27: Apple Silicon 전용 (macOS 26.4+). ld64 클래식 링커 제거.
- macOS: deployment target 27+에서 `ARCHS_STANDARD`가 x86_64 제외. Mac App Store가 arm64 전용 바이너리 허용 (Tahoe 26이 마지막 Intel 릴리스).

## SwiftUI (iOS 27 / macOS 27)

### 새 Document API
- **`Document` / `ReadableDocument` / `WritableDocument`** 프로토콜 — `FileDocument` **deprecated**. async 읽기/쓰기, 진행률 보고, 문서 URL 직접 접근, 스냅샷/증분 저장(패키지 변경분만).
- `DocumentReader` / `DocumentWriter` — `write`는 `@concurrent`(off-main).
- `NewDocumentButton` + `DocumentCreationSource` — 복수 문서 생성 소스(빈 문서/템플릿).

### 인터랙션
- **`.reorderable()`** (ForEach) + **`.reorderContainer()`** — List뿐 아니라 어떤 컨테이너에서든 드래그 재정렬. watchOS 최초 지원.
- **`.swipeActions` 일반화** + `.swipeActionsContainer()` — List 밖(LazyVStack 등)에서도 스와이프 액션.
- `alert` / `confirmationDialog`에 **item 바인딩** 추가 — `sheet(item:)` 패턴. iOS 15까지 back-deploy.
- 선택 가능한 `Text`가 iOS에서 전체 시스템 텍스트 선택 UI 사용.

### 툴바·탭
- `.visibilityPriority(_:)` — 공간 부족 시 유지할 아이템 우선순위. `ToolbarOverflowMenu`, `topBarPinnedTrailing` 배치.
- `.toolbarMinimizationBehavior(_:)` — 스크롤 시 네비게이션 바 축소 (예: `.onScrollDown`).
- **Prominent tab role** — 특정 탭(장바구니 등)을 bottom-trailing에 고정.

### 상태·성능
- **`@State`가 매크로로 재구현** — `@State`에 저장한 클래스 인스턴스가 **1회만 lazy 초기화** (뷰 re-init마다 생성되던 문제 해소). iOS 17까지 back-deploy. 일부 소스 브레이킹(기본값 + init 할당 조합 등).
- **`ContentBuilder`** — result builder 통합, Xcode 27에서 타입체크 대폭 고속화.
- **`AsyncImage` HTTP 캐싱 자동화** (서버 캐시 헤더 준수, 리컴파일 불필요) + `AsyncImage(urlRequest:)`, `.asyncImageURLSession(_:)`.
- 중첩 스택 레이아웃 리사이즈 최대 2배 고속화.
- 컨트롤 구현 통합 — 다수 AppKit/UIKit 컨트롤이 내부적으로 SwiftUI 렌더링으로 단일화.

## UIKit (iOS 27)

- **iPhone 사이드바 opt-in** — `tabBarController.sidebar.preferredPlacement = .sidebar` (가용성은 시스템 판단).
- `UITabBarController.prominentTabIdentifier`, `UINavigationItem.navigationBarMinimization`.
- **메뉴 아이콘 기본 숨김** (iPadOS 27/macOS 27 메뉴바) — `UIMenuElement.preferredImageVisibility`로 재정의.
- `UIScene.extendStateRestoration` / `completeStateRestoration` — 백그라운드↔포그라운드 전환 상태 복원 확장.
- `UIScreen.main`·화면 bounds 사용 금지 — trait의 `displayScale`, `UIWindowScene.effectiveGeometry` 사용.
- TextKit: `NSTextTable` / `NSTextBlock` 계열이 UIKit에서 사용 가능.
- Siri 연동: **View Annotations API** — 뷰에 AppEntity 주석을 달아 화면 콘텐츠("이 사진")에 Siri가 동작. 메뉴에 "Ask Siri" 자동 항목.
- scroll edge effect `.automatic`이 독자 시각으로 변경 — `.soft` 오버라이드 재검토.

## AppKit (macOS 27 Golden Gate)

- **`NSTextSelectionManager`** — 클래식 텍스트 선택 동작(클릭/드래그/더블·트리플 클릭, 텍스트 드래그)을 아무 `NSView`에나 제공. NSTextView가 이 위에 재구축.
- **UIKit 스타일 control events** (`NSControlEvents`) — 다수는 OS X 10.11까지 back-available.
- **`NSRefreshController`** — NSScrollView pull-to-refresh.
- **`NSView.cornerConfiguration`** — 컨테이너/윈도우 곡률과 동심(concentric) 코너.
- `NSStatusItem` expanded interface session API — 커스텀 상태 아이템 윈도우의 키보드 포커스 라이프사이클.
- 사이드바가 윈도우 가장자리까지 확장, 아이콘에 앱 액센트 색 복원. 모든 윈도우 코너 반경 통일.

## SwiftData

- **`sectionBy` 쿼리** — 섹션화된 fetch 결과를 SwiftUI에 직접 제공.
- **`Codable` attribute 옵션** — 서드파티 타입을 `@Model` 없이 영속화 (`#Predicate`/정렬에는 불투명, 스키마 마이그레이션 미발동 주의).
- **`ResultsObserver`** — SwiftUI 밖에서 fetch 결과 변화 관찰 (Observation 기반).
- **`HistoryObserver`** — persistent history 트랜잭션 반응 (`eventCounter` → `fetchHistory`). 서버 동기화용.

## App Intents — 신형 Siri의 통합 표면

- **App schema domains** — 인텐트/엔티티를 스키마에 적합시키면 Spotlight 시맨틱 인덱스 + Siri 오케스트레이터에 참여. SiriKit는 세대교체 완료 (공식 deprecation 표현은 보도 기준).
- **`LongRunningIntent`** — 30초 넘는 백그라운드 실행, Live Activity 진행률 자동 표시, 백그라운드 GPU/Neural Engine (신규 entitlement 필요).
- `CancellableIntent`, `UndoableIntent`, `IntentModes`(포그라운드/백그라운드 선언), `EntityCollection`(대량 엔티티 지연 해석), `SyncableEntity`(크로스 디바이스 대화 연속), `RelevantEntities`, `IndexedEntityQuery`.
- **`AppIntentsTesting`** 프레임워크 — 인텐트 테스트.

## Foundation Models 확장

- **온디바이스 모델 세대교체** — instruction following·tool calling 개선. OS 업데이트마다 모델이 바뀌므로 프롬프트 재검증 필요.
- **`LanguageModel` 프로토콜** — 임의 모델(온디바이스/서버)로 `LanguageModelSession` 구동. Anthropic(Claude)·Google(Gemini) Swift 패키지 제공.
- **`PrivateCloudComputeLanguageModel`** — PCC 서버 모델: 32K 컨텍스트, reasoning 레벨, 200만 다운로드 미만 개발자 무료 (entitlement 필요).
- **이미지 입력** (멀티모달), Vision 시스템 툴(`OCRTool`, `BarcodeReaderTool`), Spotlight 기반 로컬 RAG 툴.
- **`DynamicProfile`** — 턴별 instructions/tools/model 스왑 (에이전트 구축 블록).
- 프레임워크 오픈소스화 (Linux 포함), `fm` CLI (macOS 27), Python SDK.
- 신규 프레임워크: **Core AI** (커스텀 온디바이스 모델 실행), **Evaluations** (프롬프트/기능 품질 정량화).

## WidgetKit · Live Activities

## watchOS 27 · tvOS 27 · visionOS 27

- **watchOS 27**: Digital Crown 동적 앱 그리드, Smart Stack 엄지 탭 제스처, Foundation Models 사용 가능(PCC), HealthKit **workout zones API**(존 구성·라이브 존 업데이트), SwiftUI 재정렬 지원. Series 9+/Ultra 2+/SE 3 전용.
- **tvOS 27**: **Dynamic Type 도입** — 커스텀 플레이어 등 대응 필요. Apple TV HD·4K 1세대 지원 종료.
- **visionOS 27**: 신형 Vision Pro(M5, 90Hz hand tracking), 커스텀 공간 액세서리 API, **Spatial Preview** 프레임워크(Mac→Vision Pro 3D 핸드오프), object tracking이 iOS ARKit로 확대. RealityKit: **Gaussian splat 렌더링**, 클로스 시뮬레이션, 내비게이션 메시, soft shadows·실공간 조명(`SurroundingsLight`), 커스텀 리버브 메시, `LevelOfDetailComponent`. Reality Composer Pro 3 (Script Graph, AI Assistant).

## Deprecated (2026 사이클)

| Deprecated / 변경 | 대체 |
|---|---|
| app-delegate lifecycle (iOS 27 SDK: 실행 불가) | `UISceneDelegate` |
| SwiftUI `FileDocument` / `ReferenceFileDocument` | `ReadableDocument` / `WritableDocument` / `Document` |
| `PreviewProvider` (공식 deprecated) | `#Preview` |
| `canOpenURL(_:)` | open 시도 후 실패 처리, universal links |

| `MXMetricManager` 계열 (MetricKit) | Swift `MetricManager` (AsyncStream) |

| interface orientation / idiom 기반 레이아웃 | size class + `effectiveGeometry` |
| x86_64 (deployment 27+) | arm64 전용 |
