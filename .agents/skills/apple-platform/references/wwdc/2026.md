# WWDC 2026 — iOS 27 · iPadOS 27 · macOS 27 Golden Gate · watchOS 27 · tvOS 27 · visionOS 27

Announced June 2026, shipping in fall. **UIScene becomes mandatory**, new SwiftUI Document API, App Intents becomes the sole integration surface for the new Siri, major expansion of Foundation Models. End of the Intel Mac era. Toolchain: Xcode 27, Swift 6.4, SF Symbols 8, Icon Composer 2.

> Previous: `2022.md` → `2023.md` → `2024.md` → `2025.md` (Liquid Glass introduced)

## Requirement changes (when building with the iOS 27 SDK)

- **UIScene lifecycle mandatory** — apps using only app-delegate lifecycle **fail to launch outright** when built with the iOS 27 SDK. Binaries built with an older SDK continue to work (governed by SDK, not OS, version).
- **Launch screen mandatory** — App Store submission is rejected without `UILaunchScreen`-family Info.plist keys.
- **Liquid Glass opt-out removed** — recompiling with Xcode 27 makes the old design unselectable.
- **Automatic resize opt-in** — building with the iOS 27 SDK makes iPhone apps freely resizable on iPad and iPhone Mirroring. Idiom/orientation become meaningless as layout criteria — use size classes instead. `UIRequiresFullScreen` is redefined as "discrete resizing".
- Xcode 27: Apple Silicon only (macOS 26.4+). The classic ld64 linker removed.
- macOS: with deployment target 27+, `ARCHS_STANDARD` excludes x86_64. The Mac App Store allows arm64-only binaries (Tahoe 26 is the last Intel release).

## SwiftUI (iOS 27 / macOS 27)

### New Document API
- **`Document` / `ReadableDocument` / `WritableDocument`** protocols — `FileDocument` **deprecated**. Async read/write, progress reporting, direct document URL access, snapshot/incremental save (only saves changed parts of a package).
- `DocumentReader` / `DocumentWriter` — `write` is `@concurrent` (off-main).
- `NewDocumentButton` + `DocumentCreationSource` — multiple document creation sources (blank document/template).

### Interaction
- **`.reorderable()`** (ForEach) + **`.reorderContainer()`** — drag-to-reorder in any container, not just List. First support on watchOS.
- **Generalized `.swipeActions`** + `.swipeActionsContainer()` — swipe actions outside List too (e.g. LazyVStack).
- Added **item binding** to `alert` / `confirmationDialog` — the `sheet(item:)` pattern. Back-deployed to iOS 15.
- Selectable `Text` uses the full system text-selection UI on iOS.

### Toolbar/tabs
- `.visibilityPriority(_:)` — priority for which items stay when space is limited. `ToolbarOverflowMenu`, `topBarPinnedTrailing` placement.
- `.toolbarMinimizationBehavior(_:)` — minimizes the navigation bar on scroll (e.g. `.onScrollDown`).
- **Prominent tab role** — pins a specific tab (e.g. cart) to the bottom-trailing position.

### State/performance
- **`@State` reimplemented as a macro** — class instances stored in `@State` are now **lazily initialized only once** (fixes the problem of re-creation on every view re-init). Back-deployed to iOS 17. Some source-breaking changes (e.g. combining a default value with init assignment).
- **`ContentBuilder`** — unified result builder, dramatically faster type-checking in Xcode 27.
- **`AsyncImage` automatic HTTP caching** (honors server cache headers, no recompile needed) + `AsyncImage(urlRequest:)`, `.asyncImageURLSession(_:)`.
- Nested stack layout resize up to 2x faster.
- Unified control implementation — many AppKit/UIKit controls now render internally through SwiftUI.

## UIKit (iOS 27)

- **iPhone sidebar opt-in** — `tabBarController.sidebar.preferredPlacement = .sidebar` (availability is system-determined).
- `UITabBarController.prominentTabIdentifier`, `UINavigationItem.navigationBarMinimization`.
- **Menu icons hidden by default** (iPadOS 27/macOS 27 menu bar) — override with `UIMenuElement.preferredImageVisibility`.
- `UIScene.extendStateRestoration` / `completeStateRestoration` — extended state restoration across background↔foreground transitions.
- Stop using `UIScreen.main`/screen bounds — use trait's `displayScale`, `UIWindowScene.effectiveGeometry` instead.
- TextKit: `NSTextTable` / `NSTextBlock` family now usable in UIKit.
- Siri integration: **View Annotations API** — annotate views with AppEntity so Siri can act on on-screen content ("this photo"). Automatic "Ask Siri" menu item.
- scroll edge effect `.automatic` changes to its own distinct look — reconsider `.soft` overrides.

## AppKit (macOS 27 Golden Gate)

- **`NSTextSelectionManager`** — brings classic text-selection behavior (click/drag, double/triple click, text drag) to any `NSView`. NSTextView is rebuilt on top of it.
- **UIKit-style control events** (`NSControlEvents`) — many are back-available to OS X 10.11.
- **`NSRefreshController`** — pull-to-refresh for NSScrollView.
- **`NSView.cornerConfiguration`** — concentric corner curvature matching containers/windows.
- `NSStatusItem` expanded interface session API — keyboard focus lifecycle for custom status item windows.
- Sidebar extends to the window edge, app accent color restored to icons. Corner radius unified across all windows.

## SwiftData

- **`sectionBy` queries** — provides sectioned fetch results directly to SwiftUI.
- **`Codable` attribute option** — persist third-party types without `@Model` (opaque to `#Predicate`/sorting, and does not trigger schema migration — be careful).
- **`ResultsObserver`** — observe fetch result changes outside SwiftUI (Observation-based).
- **`HistoryObserver`** — react to persistent history transactions (`eventCounter` → `fetchHistory`). For server sync.

## App Intents — the new Siri's integration surface

- **App schema domains** — conforming intents/entities to a schema enrolls them in the Spotlight semantic index + the Siri orchestrator. SiriKit has been fully superseded (the exact official deprecation wording is per the press materials).
- **`LongRunningIntent`** — background execution beyond 30 seconds, automatic Live Activity progress display, background GPU/Neural Engine access (requires a new entitlement).
- `CancellableIntent`, `UndoableIntent`, `IntentModes` (declares foreground/background), `EntityCollection` (lazy resolution of large entity sets), `SyncableEntity` (cross-device conversation continuity), `RelevantEntities`, `IndexedEntityQuery`.
- **`AppIntentsTesting`** framework — testing intents.

## Foundation Models expansion

- **On-device model succession** — improved instruction following/tool calling. The model changes with each OS update, so prompts need re-validation.
- **`LanguageModel` protocol** — drive `LanguageModelSession` with an arbitrary model (on-device/server). Swift packages provided for Anthropic (Claude) and Google (Gemini).
- **`PrivateCloudComputeLanguageModel`** — a PCC server model: 32K context, reasoning levels, free for developers under 2 million downloads (requires an entitlement).
- **Image input** (multimodal), Vision system tools (`OCRTool`, `BarcodeReaderTool`), Spotlight-based local RAG tool.
- **`DynamicProfile`** — swap instructions/tools/model per turn (a building block for agents).
- Framework open-sourced (including Linux), `fm` CLI (macOS 27), Python SDK.
- New frameworks: **Core AI** (running custom on-device models), **Evaluations** (quantifying prompt/feature quality).

## WidgetKit · Live Activities

- **`systemExtraLargePortrait`** widget family — expanded to iOS/iPadOS/macOS 27 (previously visionOS-only).
- Dynamic Island **landscape** support + `isDynamicIslandLimitedInWidth` environment value (for narrow compact views).

## watchOS 27 · tvOS 27 · visionOS 27

- **watchOS 27**: dynamic Digital Crown app grid, Smart Stack thumb-tap gesture, Foundation Models available (via PCC), HealthKit **workout zones API** (zone configuration, live zone updates), SwiftUI reordering support. Series 9+/Ultra 2+/SE 3 only.
- **tvOS 27**: **Dynamic Type introduced** — custom players etc. need to accommodate it. Apple TV HD and 4K 1st generation support ends.
- **visionOS 27**: new Vision Pro (M5, 90Hz hand tracking), custom spatial accessory API, **Spatial Preview** framework (Mac→Vision Pro 3D handoff), object tracking expanded to iOS ARKit. RealityKit: **Gaussian splat rendering**, cloth simulation, navigation mesh, soft shadows/real-space lighting (`SurroundingsLight`), custom reverb mesh, `LevelOfDetailComponent`. Reality Composer Pro 3 (Script Graph, AI Assistant).

## StoreKit

- **12-month commitment monthly subscriptions** (iOS 26.5+) — `pricingTerms`, `Transaction.commitmentInfo`, `.preferredSubscriptionPricingTerms`.
- **Bundles & Suites** — cross-app subscription bundles (program launches later in 2026).
- OfferCodeRedemption now returns `VerificationResult`; offer codes expanded to consumables/non-consumables.

## Deprecated (2026 cycle)

| Deprecated / Change | Replacement |
|---|---|
| app-delegate lifecycle (fails to launch with iOS 27 SDK) | `UISceneDelegate` |
| SwiftUI `FileDocument` / `ReferenceFileDocument` | `ReadableDocument` / `WritableDocument` / `Document` |
| `PreviewProvider` (officially deprecated) | `#Preview` |
| `canOpenURL(_:)` | Attempt to open and handle failure, universal links |
| On Demand Resources / `NSBundleResourceRequest` | Background Assets |
| `MXMetricManager` family (MetricKit) | Swift `MetricManager` (AsyncStream) |
| `.squareBorder` / `.roundedBorder` text field styles | `.bordered` + `TextInputBorderShape` |
| Interface orientation/idiom-based layout | Size class + `effectiveGeometry` |
| x86_64 (deployment 27+) | arm64 only |
