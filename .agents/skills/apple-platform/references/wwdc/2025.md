# WWDC 2025 — iOS 26 · iPadOS 26 · macOS 26 Tahoe · watchOS 26 · tvOS 26 · visionOS 26

2025년 9월 출시. **년도 기반 버저닝 도입**(전 플랫폼 26으로 통일)과 **Liquid Glass** 디자인 시스템 전면 적용. 온디바이스 LLM(Foundation Models) 공개, iPadOS 윈도잉 개편.

> 이전: `2022.md` → `2023.md` → `2024.md` · 이후: `2026.md`

## Liquid Glass — 전 플랫폼 디자인 개편

SDK 26으로 빌드하면 표준 컴포넌트가 자동 적용. 디자인 원칙은 `../hig.md`.

- **SwiftUI**: `.glassEffect()` / `.glassEffect(in:)` / `.glassEffect(.regular.tint(_:).interactive())`, `GlassEffectContainer`로 그룹핑.
- **UIKit**: `UIGlassEffect` / `UIGlassContainerEffect`, `UIButton.Configuration.glass()` / `.prominentGlass()`. 탭바·네비게이션바 투명 기본값.
- **AppKit**: `NSGlassEffectView` / `NSGlassEffectContainerView`, `NSBackgroundExtensionView`, `NSView.LayoutRegion`, ScrollEdgeEffect(`.soft`/`.hard`), 컨트롤 크기 개편(Extra Large 추가). 상세는 `../appkit.md`.
- **앱 아이콘**: 레이어 기반 + 6가지 자동 변형(default/dark/clear light/clear dark/tinted light/tinted dark). Xcode **Icon Composer**로 제작.

## SwiftUI (iOS 26 / macOS 26)

- **`WebView` / `WebPage`** — WebKit의 SwiftUI 네이티브 API.
- **Rich Text**: `TextEditor`가 `AttributedString` 바인딩 지원.
- **`@Animatable` 매크로** — `AnimatableData` 보일러플레이트 제거 (`@AnimatableIgnored`로 제외).
- **`Chart3D`** — 3D 차트.
- macOS `List` 대규모 성능 개선 (100k+ 항목: 로딩 6배, 업데이트 16배).
- **SwiftUI Performance Instrument** (Xcode 26).
- `LazyVStack`/`LazyHStack` 중첩 스크롤뷰 동작 개선.

## UIKit (iOS 26)

- **Observable 통합** — `layoutSubviews`·cell configuration handler에서 `@Observable` 자동 추적, **`updateProperties()`** 라이프사이클 메서드(레이아웃 전 실행).
- **Scene 필수화 예고** — `UIWindow(windowScene:)` 외 모든 init deprecated, 레거시 `UIApplicationDelegate` 콜백 deprecated. **iOS 27부터 scene lifecycle 필수**.

## iPadOS 26

- 윈도잉 개편 — 자유 배치 리사이즈 윈도우, **메뉴바** 도입.
- `NavigationSplitView` 리사이즈 윈도우에서 자동 컬럼 show/hide.

## watchOS 26 · tvOS 26

- watchOS 26: Liquid Glass 적용, Smart Stack 힌트 강화.
- tvOS 26: Liquid Glass 적용. `UIScreen.mainScreen` deprecated, TLS 1.0/1.1 제거(1.2 최소).

## visionOS 26

- **3D 레이아웃**: `Alignment3D`, `SpatialContainer`, `SpatialOverlay`.
- **`.manipulable`** — 손 제스처로 객체 이동/회전.
- 환경 오클루전(가상 객체가 실물에 가려짐), **Look-to-Scroll**(시선 스크롤).
- **`RemoteImmersiveSpace`** — macOS Tahoe 앱에서 Vision Pro로 몰입 콘텐츠 스트리밍.
- Volume 내 alert/sheet/popover, 콘텐츠 경계 밖 "peeking".
- RealityKit 엔티티 `Observable` 적합, hand tracking 3배 고속화, PS VR2 Sense 컨트롤러.
- **visionOS 위젯** — 공간 고정 위젯.

## 플랫폼 공통 / 프레임워크

- **Foundation Models 프레임워크** — 온디바이스 Apple Intelligence LLM 직접 호출 (`LanguageModelSession`, `@Generable` 구조화 출력, 스트리밍, tool calling).
- **App Intents**: 인터랙티브 스니펫(위젯형 결과 UI), Visual Intelligence 연동.
- **AlarmKit** — 서드파티 알람/타이머 (잠금화면·Dynamic Island).
- **WidgetKit**: `WidgetPushHandler` — 푸시 기반 위젯 갱신. CarPlay/visionOS 위젯 확장.
- **SwiftData**: 모델 상속(class inheritance) 지원.
- StoreKit: `SubscriptionOfferView` 등 머천다이징 개선.

## Deprecated (2025 사이클)

| Deprecated | 대체 |
|---|---|
| `UIWindow` init (windowScene 제외) | `UIWindow(windowScene:)` |
| 레거시 `UIApplicationDelegate` 라이프사이클 콜백 | `UISceneDelegate` (iOS 27 필수) |
| `UIScreen.mainScreen` (tvOS 26) | scene 기반 화면 접근 |
| TLS 1.0/1.1 (tvOS 26) | TLS 1.2+ |
