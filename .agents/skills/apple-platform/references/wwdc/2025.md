# WWDC 2025 — iOS 26 · iPadOS 26 · macOS 26 Tahoe · watchOS 26 · tvOS 26 · visionOS 26

Released September 2025. **Introduces year-based versioning** (unified to 26 across all platforms) and full adoption of the **Liquid Glass** design system. On-device LLM (Foundation Models) announced, iPadOS windowing overhaul.

> Previous: `2022.md` → `2023.md` → `2024.md` · Later: `2026.md`

## Liquid Glass — cross-platform design overhaul

Building with SDK 26 automatically applies standard components. Design principles in `../hig.md`.

- **SwiftUI**: `.glassEffect()` / `.glassEffect(in:)` / `.glassEffect(.regular.tint(_:).interactive())`, grouped with `GlassEffectContainer`.
- **UIKit**: `UIGlassEffect` / `UIGlassContainerEffect`, `UIButton.Configuration.glass()` / `.prominentGlass()`. Transparent tab bar/navigation bar defaults.
- **AppKit**: `NSGlassEffectView` / `NSGlassEffectContainerView`, `NSBackgroundExtensionView`, `NSView.LayoutRegion`, ScrollEdgeEffect (`.soft`/`.hard`), control size overhaul (Extra Large added). Details in `../appkit.md`.
- **App icons**: layer-based + 6 automatic variants (default/dark/clear light/clear dark/tinted light/tinted dark). Authored with Xcode's **Icon Composer**.

## SwiftUI (iOS 26 / macOS 26)

- **`WebView` / `WebPage`** — SwiftUI-native API for WebKit.
- **Rich Text**: `TextEditor` supports `AttributedString` binding.
- **`@Animatable` macro** — removes `AnimatableData` boilerplate (exclude with `@AnimatableIgnored`).
- **`Chart3D`** — 3D charts.
- Major macOS `List` performance improvements (100k+ items: 6x faster loading, 16x faster updates).
- **SwiftUI Performance Instrument** (Xcode 26).
- Improved behavior for nested scroll views in `LazyVStack`/`LazyHStack`.

## UIKit (iOS 26)

- **Observable integration** — `@Observable` automatically tracked in `layoutSubviews` and cell configuration handlers, new **`updateProperties()`** lifecycle method (runs before layout).
- **Scene mandate coming** — all `UIWindow` inits other than `UIWindow(windowScene:)` deprecated, legacy `UIApplicationDelegate` callbacks deprecated. **Scene lifecycle becomes mandatory starting iOS 27**.

## iPadOS 26

- Windowing overhaul — freely placed, resizable windows, **menu bar** introduced.
- `NavigationSplitView` automatically shows/hides columns in resizable windows.

## watchOS 26 · tvOS 26

- watchOS 26: Liquid Glass adopted, stronger Smart Stack hints.
- tvOS 26: Liquid Glass adopted. `UIScreen.mainScreen` deprecated, TLS 1.0/1.1 removed (1.2 minimum).

## visionOS 26

- **3D layout**: `Alignment3D`, `SpatialContainer`, `SpatialOverlay`.
- **`.manipulable`** — move/rotate objects via hand gestures.
- Environmental occlusion (virtual objects occluded by real objects), **Look-to-Scroll** (gaze-based scrolling).
- **`RemoteImmersiveSpace`** — stream immersive content from a macOS Tahoe app to Vision Pro.
- Alert/sheet/popover within a Volume, "peeking" outside content bounds.
- RealityKit entities conform to `Observable`, 3x faster hand tracking, PS VR2 Sense controller.
- **visionOS widgets** — spatially anchored widgets.

## Cross-Platform / Frameworks

- **Foundation Models framework** — call the on-device Apple Intelligence LLM directly (`LanguageModelSession`, `@Generable` structured output, streaming, tool calling).
- **App Intents**: interactive snippets (widget-style result UI), Visual Intelligence integration.
- **AlarmKit** — third-party alarms/timers (Lock Screen, Dynamic Island).
- **WidgetKit**: `WidgetPushHandler` — push-based widget refresh. CarPlay/visionOS widget expansion.
- **SwiftData**: model inheritance (class inheritance) support.
- StoreKit: merchandising improvements such as `SubscriptionOfferView`.

## Deprecated (2025 cycle)

| Deprecated | Replacement |
|---|---|
| `UIWindow` inits (other than windowScene) | `UIWindow(windowScene:)` |
| Legacy `UIApplicationDelegate` lifecycle callbacks | `UISceneDelegate` (mandatory in iOS 27) |
| `UIScreen.mainScreen` (tvOS 26) | Scene-based screen access |
| TLS 1.0/1.1 (tvOS 26) | TLS 1.2+ |
