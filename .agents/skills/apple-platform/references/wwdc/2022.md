# WWDC 2022 — iOS 16 · iPadOS 16 · macOS 13 Ventura · watchOS 9 · tvOS 16

Released September–October 2022. Full SwiftUI navigation overhaul (NavigationStack), Lock Screen widgets, Live Activities, and App Intents debut.

> Later years: `2023.md` (@Observable, SwiftData, visionOS) → `2024.md` → `2025.md` (Liquid Glass) → `2026.md`

## SwiftUI (iOS 16 / macOS 13 / watchOS 9 / tvOS 16)

### Navigation overhaul
- **`NavigationStack`** — value-based programmatic navigation. Replaces `NavigationView`.
- **`NavigationSplitView`** — 2/3-column multi-column layout (iPad/Mac). Automatically collapses to a stack in compact.
- **`NavigationPath`** — type-erased path. `Codable` state restoration.
- **`.navigationDestination(for:)`** — declares a destination per value type.

### Layout
- **`Grid` / `GridRow`** — static two-dimensional grid.
- **`Layout` protocol** — custom layout containers.
- **`AnyLayout`** — animates transitions between layouts based on conditions.
- **`ViewThatFits`** — picks the first view that fits the available space.

### New views/modifiers
- **Swift Charts** — declarative charting framework (`Chart`, `BarMark`, `LineMark` …).
- **`ShareLink`** + **`Transferable`** — share sheet, type-safe data transfer (including drag and drop).
- **`PhotosPicker`** (PhotosUI) — photo picking.
- **`ImageRenderer`** — renders SwiftUI views to image/PDF.
- **`Gauge`** (existing on watchOS 7 → extended to iOS 16/macOS 13), **`MultiDatePicker`**, **`TextField(axis: .vertical)`** (auto-expanding)
- **`.presentationDetents(_:)`** / **`.presentationDragIndicator(_:)`** — resizable sheets (half sheets).
- **`Table`** — multi-column table for iPadOS/macOS (extended from macOS 12 to iPadOS 16).
- Scroll control: **`.scrollDismissesKeyboard(_:)`**, **`.scrollContentBackground(_:)`**, **`.scrollIndicators(_:)`**

### macOS 13 Scene
- **`MenuBarExtra`** — SwiftUI menu bar apps.
- **`Window`** — single unique window scene.
- **`openWindow`** environment action.

## UIKit (iOS 16)

- **`UIHostingConfiguration`** — use SwiftUI content directly inside UIKit cells.
- **`UICalendarView`** — date selection/decoration calendar.
- **`UIFindInteraction`** — find/replace text UI.
- **VisionKit**: `DataScannerViewController` (live barcode/text scanning), `ImageAnalysisInteraction` (Live Text).
- **`UIPasteControl`** — explicit paste button without a permission banner. Introduces user notification for programmatic pasteboard access.
- **Self-resizing cells** enabled by default (`selfSizingInvalidation`).
- **`UIEditMenuInteraction`** — modernizes the edit menu. `UIMenuController` formally deprecated.
- **UINavigationItem styles** — `.navigator` / `.browser` / `.editor`, document rename (`renameDelegate`), title menu.
- **Stage Manager** (iPadOS 16) — request window geometry via `UIWindowScene.requestGeometryUpdate(_:)`.

## AppKit (macOS 13 Ventura)

- **Stage Manager** support.
- **`NSComboButton`** — combines a button with a pull-down menu.
- **`NSColorWell`** new styles — `.minimal`, `.expanded`.
- Strengthened SwiftUI ↔ AppKit interop (e.g. `NSHostingController` sizing options).

## watchOS 9

- **ClockKit deprecated** → WidgetKit accessory complications (`accessoryCircular` / `accessoryCorner` / `accessoryRectangular` / `accessoryInline`).
- **`.backgroundTask(_:action:)`** — SwiftUI background task handling.
- **CallKit** support on watchOS (VoIP).
- HealthKit: **`HKWorkoutActivity`** — multisport (triathlon) workout composition.

## tvOS 16

- **DeviceDiscoveryUI** — connect iPhone/iPad as input/companion devices for tvOS apps.

## Cross-Platform / Other Frameworks

- **Lock Screen widgets** (iOS 16) — WidgetKit accessory families extended to iOS.
- **Live Activities / ActivityKit** (iOS 16.1) — real-time activity on the Lock Screen and Dynamic Island.
- **App Intents** (iOS 16) — Swift code-based intents. Replaces SiriKit custom intents, automatically surfaced to Shortcuts.
- **WeatherKit** — weather data (Swift async API + REST).
- **Major MapKit update** — 3D City Experience fully opened up, **Look Around API**, Apple Maps Server API (REST).
- **Messages Collaboration API / SharedWithYou** — integrates an app's collaborative content into Messages and FaceTime.
- **Focus filters** — App Intents-based, per-Focus-mode app content filtering.
- **RoomPlan** — LiDAR indoor 3D scanning.
- **Passkeys** (AuthenticationServices) — WebAuthn-based passwordless sign-in.
- **Metal 3** — MetalFX upscaling, fast resource loading, mesh shaders.
- **DriverKit for iPadOS** — USB/Audio/PCI drivers extended to iPad.
- Foundation: **`Regex` / `RegexBuilder`**, **`Duration` / `Clock`** (Swift 5.7 generation) — details in `../foundation.md`.

## Deprecated (2022 cycle)

| Deprecated | Replacement |
|---|---|
| `NavigationView` | `NavigationStack` / `NavigationSplitView` |
| ClockKit complications | WidgetKit accessory families |
| SiriKit custom intents | App Intents |
| `UIMenuController` | `UIEditMenuInteraction` |
