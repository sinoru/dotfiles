# WWDC 2022 — iOS 16 · iPadOS 16 · macOS 13 Ventura · watchOS 9 · tvOS 16

2022년 9–10월 출시. SwiftUI 네비게이션 전면 개편(NavigationStack), 잠금화면 위젯, Live Activities, App Intents 등장.

> 이후 년도: `2023.md` (@Observable, SwiftData, visionOS) → `2024.md` → `2025.md` (Liquid Glass) → `2026.md`

## SwiftUI (iOS 16 / macOS 13 / watchOS 9 / tvOS 16)

### 네비게이션 개편
- **`NavigationStack`** — 값 기반 프로그래매틱 네비게이션. `NavigationView` 대체.
- **`NavigationSplitView`** — 2/3열 멀티 컬럼 (iPad/Mac). compact에서 자동 스택 축소.
- **`NavigationPath`** — type-erased 경로. `Codable` 상태 복원.
- **`.navigationDestination(for:)`** — 값 타입별 목적지 선언.

### 레이아웃
- **`Grid` / `GridRow`** — 정적 2차원 그리드.
- **`Layout` 프로토콜** — 커스텀 레이아웃 컨테이너.
- **`AnyLayout`** — 조건에 따른 레이아웃 전환 애니메이션.
- **`ViewThatFits`** — 공간에 맞는 첫 번째 뷰 선택.

### 신규 뷰·수정자
- **Swift Charts** — 선언적 차트 프레임워크 (`Chart`, `BarMark`, `LineMark` …).
- **`ShareLink`** + **`Transferable`** — 공유 시트, 타입 안전 데이터 전송(드래그 앤 드롭 포함).
- **`PhotosPicker`** (PhotosUI) — 사진 선택.
- **`ImageRenderer`** — SwiftUI 뷰 → 이미지/PDF 렌더.
- **`Gauge`**(watchOS 7 기존 → iOS 16/macOS 13 확장), **`MultiDatePicker`**, **`TextField(axis: .vertical)`**(자동 확장)
- **`.presentationDetents(_:)`** / **`.presentationDragIndicator(_:)`** — 리사이즈 가능 시트(하프 시트).
- **`Table`** — iPadOS/macOS 멀티 컬럼 테이블 (macOS 12에서 iPadOS 16으로 확장).
- 스크롤 제어: **`.scrollDismissesKeyboard(_:)`**, **`.scrollContentBackground(_:)`**, **`.scrollIndicators(_:)`**

### macOS 13 Scene
- **`MenuBarExtra`** — SwiftUI 메뉴바 앱.
- **`Window`** — 단일 고유 윈도우 scene.
- **`openWindow`** environment action.

## UIKit (iOS 16)

- **`UIHostingConfiguration`** — UIKit 셀 안에 SwiftUI 콘텐츠 직접 사용.
- **`UICalendarView`** — 날짜 선택/장식 캘린더.
- **`UIFindInteraction`** — 텍스트 찾기/바꾸기 UI.
- **VisionKit**: `DataScannerViewController`(바코드/텍스트 라이브 스캔), `ImageAnalysisInteraction`(Live Text).
- **`UIPasteControl`** — 붙여넣기 권한 배너 없는 명시적 paste 버튼. 프로그래매틱 pasteboard 접근 시 사용자 알림 도입.
- **Self-resizing cells** 기본 활성화 (`selfSizingInvalidation`).
- **`UIEditMenuInteraction`** — 편집 메뉴 현대화. `UIMenuController` 정식 deprecated.
- **UINavigationItem 스타일** — `.navigator` / `.browser` / `.editor`, 문서 rename(`renameDelegate`), 타이틀 메뉴.
- **Stage Manager** (iPadOS 16) — `UIWindowScene.requestGeometryUpdate(_:)`로 윈도우 geometry 요청.

## AppKit (macOS 13 Ventura)

- **Stage Manager** 지원.
- **`NSComboButton`** — 버튼 + 풀다운 메뉴 결합.
- **`NSColorWell`** 새 스타일 — `.minimal`, `.expanded`.
- SwiftUI ↔ AppKit 협업 강화 (`NSHostingController` 크기 옵션 등).

## watchOS 9

- **ClockKit deprecated** → WidgetKit accessory 컴플리케이션 (`accessoryCircular` / `accessoryCorner` / `accessoryRectangular` / `accessoryInline`).
- **`.backgroundTask(_:action:)`** — SwiftUI 백그라운드 태스크 처리.
- **CallKit** watchOS 지원 (VoIP).
- HealthKit: **`HKWorkoutActivity`** — 멀티스포츠(트라이애슬론) 워크아웃 구성.

## tvOS 16

- **DeviceDiscoveryUI** — iPhone/iPad를 tvOS 앱의 입력/연동 기기로 연결.

## 플랫폼 공통 / 기타 프레임워크

- **잠금화면 위젯** (iOS 16) — WidgetKit accessory 패밀리가 iOS로 확장.
- **Live Activities / ActivityKit** (iOS 16.1) — 잠금화면·Dynamic Island 실시간 활동.
- **App Intents** (iOS 16) — Swift 코드 기반 인텐트. SiriKit custom intents 대체, Shortcuts 자동 노출.
- **WeatherKit** — 날씨 데이터 (Swift async API + REST).
- **MapKit 대업데이트** — 3D City Experience 전면 개방, **Look Around API**, Apple Maps Server API(REST).
- **Messages Collaboration API / SharedWithYou** — 앱의 협업 콘텐츠를 메시지·FaceTime에 연동.
- **Focus filters** — App Intents 기반, 포커스 모드별 앱 콘텐츠 필터.
- **RoomPlan** — LiDAR 실내 3D 스캔.
- **Passkeys** (AuthenticationServices) — WebAuthn 기반 무비밀번호 로그인.
- **Metal 3** — MetalFX 업스케일링, fast resource loading, mesh shaders.
- **DriverKit for iPadOS** — USB/Audio/PCI 드라이버가 iPad로 확장.
- Foundation: **`Regex` / `RegexBuilder`**, **`Duration` / `Clock`** (Swift 5.7 세대) — 상세는 `../foundation.md`.
